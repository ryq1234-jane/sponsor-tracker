# 협찬 체크리스트

택배로 받는 협찬·체험단의 신청부터 리뷰 마감까지 한곳에서 관리하는 웹페이지입니다.

## 기능
- 신청 → 선정 → 수령 → 리뷰 단계를 카드에서 바로 체크
- 수령 체크 시 "수령 후 N일 이내" 기준으로 리뷰 마감일 자동 계산
- 리뷰 마감일 가까운 순 정렬, 3일 이내 주황 · 지나면 빨강 표시
- 이메일 로그인, 휴대폰·컴퓨터 어디서나 같은 목록 (Supabase)

## 파일 구성
| 파일 | 역할 |
|---|---|
| `index.html` | 화면 구성 |
| `style.css` | 디자인 |
| `app.js` | 동작 |
| `config.js` | Supabase 연결 정보 (공개용 publishable key만) |
| `supabase.sql` | 데이터베이스 표와 보안 규칙 (Supabase SQL Editor에서 실행) |
| `tests/logic.test.js` | 계산·표시 로직 테스트 |

## 테스트
코드를 고친 뒤 아래 명령으로 계산 로직(마감일, 체크 단계, 정렬, 카드 표시, 메모 링크)을 확인할 수 있습니다.

```bash
node tests/logic.test.js
```

## 배포
`main` 브랜치에 push하면 Vercel이 자동으로 배포합니다.
